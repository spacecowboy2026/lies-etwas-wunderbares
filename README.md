# Lies etwas Wunderbares

Zeitlose Texte, die es wert sind, gelesen zu werden: Essays, Reden und Briefe. Eine Karte pro Text, ein Klick öffnet das Original.

Nach dem Vorbild von [Read Something Wonderful](https://readsomethingwonderful.com). Jede Karte zeigt die Seite, auf der man den Text lesen kann; die Rechte an den Texten und Seiten liegen bei ihren Urhebern.
